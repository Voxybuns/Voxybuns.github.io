**@icons** is a free and open source library of icons, designed to be used as custom node icons by *Godot Engine* users, either within their game projects or as part of their plug-ins and add-ons.

<figure>
  <img src="/assets/img/projects/at-icons-thumbnail-large.png">
</figure>

The library contains **400 vector (SVG) icons**, designed on a 16×16 canvas and styled to fit right at home alongside the existing Godot Engine user interface icons.

Each icon is available in 4 colors corresponding to the default node types found in the engine (`Node`, `Node2D`, `Node3D`, and `Control`), and set up to adapt to your preferred editor scaling and color scheme.

**@icons** is available under the [MIT License](https://github.com/Voxybuns/at-icons/blob/main/LICENSE), and can be downloaded from [itch.io](https://voxybuns.itch.io/at-icons) (where you can also donate if you'd like to financially support the project) and the [Godot Asset Store](https://store.godotengine.org/asset/voxy/at-icons/). There is also a [GitHub repository](https://github.com/Voxybuns/at-icons) where you can suggest new icons and report issues with the library.
